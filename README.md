# Panvel AI Assistant

Assistente conversacional desenvolvido para o desafio técnico de IA Generativa do Grupo Panvel.

## Estrutura

O projeto será composto por:

- Backend em Python/FastAPI
- Frontend em React + TypeScript
- RAG para consulta às bulas de medicamentos
- Tool Calling para consulta de filiais
- Streaming de respostas
- Observabilidade
- Execução via Docker
